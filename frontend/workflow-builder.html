Connecting

Hover a node and drag its blue dot onto another node to draw an arrow. Click an arrow to label it (Yes/No for a condition's branches) or delete it.

Loops & jumps

There is no loop or jump shape. Build a loop by drawing an arrow back to an earlier step from a condition's "repeat" branch; its other branch is the exit. A jump is simply an arrow to any target node.

Rules

One Start, one Entry User, one End per workflow. A linked form is required before saving.
